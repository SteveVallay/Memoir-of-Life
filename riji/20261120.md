# 11月16日－19日，中山医院住院

11月16日住院复查。

前面已经做了两个周期的一线治疗，吉西他滨＋顺铂化疗，加英飞凡免疫治疗。这次复查结果不太好，原来的病灶没有明显缩小，又发现了新的病灶。

之前也知道，iCC一线治疗并不是对所有人都有效，但看到这个结果还是有些意外。两个周期没有达到预期，只能考虑换方案。

中山医院主任给出的二线选择是参加实验组，方案为冷冻消融＋双免疫（齐倍安）＋仑伐替尼。

中山医院之前做过冷冻消融＋单免疫（信迪利单抗）＋仑伐替尼的方案，据说效果不错。这次实验组改成了双免疫。主任说风险相对较小，有效率大约30%。当时没有问清楚这个30%是指病灶缩小，还是包括病情控制，后面再确认。

目前也没有其他特别明确的备选方案，所以决定先试这个方案。

11月19日早上9点多开始做冷冻消融，到11点多结束。局部麻醉加静脉麻醉，整个过程感觉不明显。下午抽血化验，如果检查结果没有问题，估计20日开始双免疫（齐倍安）和仑伐替尼治疗。

这几天妈妈和妹夫杨帅在医院陪护，我有时间就过去看看。父亲在老家也比较担心，准备把租地的事情处理完以后过来。

# 11月16日－19日 外婆住院-公利医院

与此同时，孩子外婆身体也出了问题。检查发现心血管再次接近堵塞，之前已经装过两个支架，这次医生建议做心脏搭桥手术。

孩子妈妈去中山医院咨询过，医生说可以做，手术也比较成熟，已经开了住院单，现在等床位，估计要1－2周。

外婆这几天先住在家附近医院的ICU，那边医生也建议尽快转院做搭桥手术。11月19日先出院回家，等中山医院的床位通知。

最近两边的事情赶到了一起。一边是冷冻消融和后续治疗，一边是等着做心脏搭桥手术。事情不少，只能一件一件处理。

希望接下来都能顺利一些。

# 读佛经有感

这几天读佛经，对“无常”二字又多了一些体会。

人生中的很多事情，其实都是无常的，刹那生灭，并不会一直按照自己的想法发展。顺境如此，逆境也是如此。既然如此，就不必生太多执念。

《法句譬喻经》中说：

有常必无常，富贵必贫穷，聚合必有离，强健必当死。

《金刚经》中也说：

一切有为法，如梦幻泡影，如露亦如电，应作如是观。

人生种种，来了就面对，去了也不强留。好的时候知道它不会永远如此，难的时候也知道终会过去。

如如不动，无所住而生其心。

尽力做好眼前该做的事情，其余的，少一些执着，随缘而行。
